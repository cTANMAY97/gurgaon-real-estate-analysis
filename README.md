# gurgaon-real-estate-analysis
Exploratory Data Analysis (EDA) of Gurgaon Real Estate data using Python, Pandas, NumPy, Matplotlib, and Seaborn to uncover property pricing trends, locality insights, and market patterns.

Project Description

Gurgaon Real Estate Market Analysis – Exploratory Data Analysis (EDA)

This project focuses on performing Exploratory Data Analysis (EDA) on Gurgaon real estate data to gain insights into property prices, locality-wise trends, and key market patterns. Using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn, the project involves data cleaning, preprocessing, feature engineering, and visualization to identify factors influencing property prices and buyer preferences.

Key Highlights:
    1.Cleaned and preprocessed raw real estate data by handling missing values, duplicates, and inconsistencies.
    2.Performed univariate, bivariate, and multivariate analysis to understand property characteristics.
    3.Analyzed locality-wise property prices, average rates per square foot, and price distributions.
    4.Explored relationships between area, BHK count, price, and amenities using statistical methods and visualizations.
    5.Created correlation heatmaps, scatter plots, box plots, histograms, and bar charts to identify market trends and outliers.
    6.Derived actionable insights on premium localities, costliest properties, and factors affecting real estate pricing in Gurgaon.

Tools & Technologies Used:
    Programming Language: Python
    Libraries: Pandas, NumPy, Matplotlib, Seaborn
    Techniques: Data Cleaning, EDA, Data Visualization, Statistical Analysis, Feature Engineering
    Environment: Jupyter Notebook
    
Objective

To transform raw real estate data into meaningful insights that help understand Gurgaon’s property market dynamics and support data-driven decision-making for buyers, investors, and real estate stakeholders.
